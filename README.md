# STORE WAR - سامانه جامع مدیریت فروش، فعالیت‌های میدانی و پلانوگرام

پلتفرم مدرن و سبک تحت وب و PWA برای مدیریت قلمرو، فروشگاه‌ها، فعالیت‌های ویزیت، تطبیق اکسل فروش، پلانوگرام قفسه و رتبه‌بندی تیم فروش.

## ویژگی‌های کلیدی
- **بدون وابستگی و کاملاً مستقل**: بدون نیاز به سرورهای مسدود یا سرویس‌های محدود در ایران
- **پشتیبانی PWA**: قابلیت نصب مستقیم روی اندروید، iOS و دسکتاپ
- **پایگاه داده سبک و منعطف**: قابلیت کارکرد محلی سریع و امکان اتصال به هر دیتابیس ابری
- **کاتالوگ پویا و هوشمند**: تعریف دستی هر نوع برند و کالا، تفکیک مدل‌ها و پکینگ (توئین، نرمال و...) و استخراج خودکار از فایل‌های فروش
- **پلانوگرام قفسه Drag & Drop**: چیدمان تعاملی قفسه و تطابق شواهد ویزیتورها
- **سطوح دسترسی دقیق**: تفکیک دسترسی مدیر کل، مدیر نمایندگی، سرپرست، ویزیتور و پشتیبانی

## راهنمای راه‌اندازی و اجرا

### ۱. نیازمندی‌ها
- Node.js نسخه 18 یا بالاتر
- npm یا pnpm یا yarn

### ۲. نصب پکیج‌ها
```bash
npm install
```

### ۳. اجرای محیط توسعه
```bash
npm run dev
```
برنامه به طور پیش‌فرض روی پورت `3000` یا `5173` اجرا می‌شود.

### ۴. ساخت نسخه نهایی جهت استقرار روی هاست یا گیت‌هاب پیجز (Production Build)
```bash
npm run build
```
فایل‌های خروجی در پوشه `dist` تولید می‌شوند و می‌توانید آن‌ها را روی هر هاست، سرور لینوکس، Nginx، Cloudflare Pages یا GitHub Pages مستقر کنید.
